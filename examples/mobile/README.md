# Mobile Example

This Expo app exercises `@fidibeki/mobile` against a host-owned session endpoint and screenshot
provider. Its `💬` button is deliberately owned and positioned by the example app; the SDK injects
no launcher and opens only when that trigger calls `useFidibekiFeedback().open()`.

```sh
pnpm install
pnpm --filter @fidibeki/mobile-example prebuild
pnpm --filter @fidibeki/mobile-example android
# or
pnpm --filter @fidibeki/mobile-example ios
```

Copy `.env.example` into the local environment and replace both example hosts. The widget base URL
serves Fidibeki's public mobile submit and attachment-completion routes. The session URL belongs to
the integrating application's authenticated backend and must never return or embed a tenant API key.
The optional screenshot URL demonstrates a host-owned screenshot provider independently of the
Fidibeki widget edge; a real application can replace it with its own user-initiated native capture
or picker.

`android/` and `ios/` are generated by `expo prebuild --clean` and intentionally ignored. The
committed `app.json`, package manifest, TypeScript configuration, and application source fully
regenerate both native projects. Camera, image-library, and legacy storage permissions are blocked
in `app.json`.
