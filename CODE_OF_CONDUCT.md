# Code of conduct

We want this project to be a respectful place to collaborate. Treat people with care, assume good intent, give technical feedback about the work rather than the person, and respect requests for privacy.

Harassment, discrimination, threats, doxxing, or publishing another person's private information are not acceptable.

Report a conduct concern privately to the maintainers through the security reporting channel in [SECURITY.md](SECURITY.md). Maintainers may remove content, limit participation, or take other action needed to protect participants.
